# Почему именно эта цена

Презентация-обоснование стоимости для клиента. Сделана на [Reveal.js](https://revealjs.com/), один HTML-файл, без сборки.

## Просмотр

Откройте `index.html` в браузере (двойной клик) или зайдите на опубликованную версию через GitHub Pages.

## Управление

- `→` / `Space` — следующий слайд
- `←` — предыдущий
- `Esc` — обзор всех слайдов
- `F` — полноэкранный режим
- `S` — заметки спикера

## Редактирование

Весь контент и стили в одном файле — `index.html`. Структура:

- **CSS-переменные** в `:root` — цвета и шрифты меняются в одном месте
- **Слайды** — каждый `<section>` внутри `.slides` это один слайд
- **Шаблоны слайдов** — классы `.title-slide`, `.section-slide`, `.quote-slide`, `.cta-slide`

## Деплой

Проект публикуется через GitHub Pages автоматически из ветки `main`.
